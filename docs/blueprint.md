# **App Name**: TeamSync

## Core Features:

- User Authentication: Secure sign-up and login with password hashing and session management for all team members.
- Project Management: Create, view, edit, and delete projects with defined titles and descriptions. Each project acts as a container for tasks and assigned team members.
- Team & Role Assignment: Invite users to specific projects and assign them roles (e.g., 'Admin', 'Member') with corresponding access permissions for tasks and project settings.
- Task Management: Create detailed tasks within projects, assign them to team members, set due dates, and update their status (e.g., To Do, In Progress, Done).
- Personal Dashboard: A personalized dashboard view displaying tasks assigned to the current user, their current status, and highlighting any overdue items.
- AI Task Suggester Tool: A generative AI tool that suggests potential sub-tasks or action items when a new project description is provided, streamlining project breakdown.

## Style Guidelines:

- Primary color: A deep, professional blue (#1F457A) to convey trust and productivity, anchoring the UI elements and important actions.
- Background color: A very light, subtle bluish-gray (#F0F2F4) to ensure a clean, uncluttered workspace and minimize eye strain.
- Accent color: A vibrant teal (#26D9CA) for highlighting key information, calls to action, and visual cues related to progress or completion.
- Body and headline font: 'Inter' (sans-serif) for its modern, highly readable, and neutral aesthetic, suitable for clear task and project management information.
- Use a consistent set of minimalist line icons for navigation, task actions, and status indicators, ensuring quick comprehension and a modern feel.
- Employ a clean, card-based layout for projects and tasks, utilizing ample white space for improved readability and focus. Implement responsive design for desktop and tablet usage.
- Subtle and quick animations for state changes (e.g., task status updates, form submissions) to provide visual feedback without distraction.
